# Source data and attribution

`week1_nodes.tsv` and `week1_edges.tsv` are the unmodified DTU 02805 frozen
release dated 26 August 2026, obtained from:
https://sunelehmann.com/socialgraphs2026-web/data/

`marvel_pages.zip` is downloaded by the analysis script and excluded from Git.
The archive contains the full Wikipedia text for the same 303 node IDs.
Input SHA-256 checksums are recorded in `weeks/week6/results.json`.

`week6_audit.json` contains selected passages from that snapshot for inspection.
They are attributable to the contributors of the corresponding Wikipedia
articles (article URLs are in results.json). Wikipedia text is available under
its applicable CC BY-SA terms; consult each article history for authorship.
These are AI-assisted case checks, not independent human labels.
